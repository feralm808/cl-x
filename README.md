# Cl6zy's Creator Hub

Actúa como un desarrollador web experto y diseñador UI/UX especializado en plataformas de Roblox y comunidades de gaming. Necesito que me diseñes el código completo (HTML, Tailwind CSS y JavaScript) para una página web personal y colaborativa con un diseño estético de tarjeta de perfil.

Aquí están los detalles y requerimientos exactos que debe cumplir la página:

1. Estética y Diseño Visual (Inspirado en Peek Store / plataformas nocturnas de Roblox):
- Fondo principal en azul oscuro profundo (#060913).
- Tarjetas estilo "glassmorphism" con gradientes oscuros translúcidos, bordes con brillos sutiles en azul/celeste (#111827 / #1f2937 con bordes de 1px translúcidos) y efecto de desenfoque.
- Tipografía moderna, limpia y minimalista.

2. Contenido del Perfil Personal (Datos fijos e integrados):
- Nombre de usuario / Roblox ID: "cl6zy" (mostrado de forma limpia y destacada).
- Rol personalizado: Insignia visual superior que diga "Creador de Contenido" con estilo y color distintivo (morado/azulado).
- Biografía personal editable: "Desarrollador de experiencias en Roblox, programador en Luau y creador de contenido."
- Foto de perfil: Estructurada para mostrar el avatar de Roblox de forma limpia (con contenedor optimizado y diseño de escudo/verificado).

3. Redes Sociales y Reglas de Enlaces:
- TikTok: Enlace directo funcional hacia el perfil web (https://www.tiktok.com/@claasix) con su respectivo icono.
- Discord: Debe mostrarse estrictamente como texto estático con el identificador "@cl6zy" (con icono de Discord), sin abrir ninguna página web ni generar enlaces rotos.

4. Métricas y Estadísticas:
- Un bloque de estadísticas de seguidores totales (ej. 12,500) preparado con una variable numérica clara en el código JavaScript para que se pueda actualizar manualmente de manera rápida cada día.
